# Katya Browser Lab — дизайн-бриф

Общий документ для всех, кто правит панель (`static/index.html`, `static/scenarios.html`): люди, Claude, Codex.
Цель: одна спокойная система, где функции сгруппированы по задаче, а не по дате появления.

## Правила

1. **Стили живут в `static/katya.css`.** Он подключается последней строкой в `<head>` каждой страницы:
   `<link rel="stylesheet" href="/katya.css">`. Новые цвета, радиусы, отступы берутся только из токенов
   (`--surface`, `--line`, `--txt-2`, `--accent`, `--rec`, `--info`, `--warn`, `--r-s/m/l`).
   Inline `<style>` в HTML постепенно сокращаем до разметочных мелочей; новых «слоёв» с переопределением
   `:root` там не добавляем.
2. **Один вид кнопок.** Обычная кнопка: 34px, 12px/700, граница `--line`, фон `--surface-3`.
   Главное действие страницы: `.btn-go` (мятная заливка). Запись/опасное: цвет `--rec`.
   Повтор: `--info`. Второстепенные (копировать, очистить): без фона и границы.
3. **Иерархия карточки вкладки сверху вниз:** превью → строка состояния (точка, имя, статус, время) →
   кнопки вкладки → прогресс сценария → блок «Запись шагов и сценарии» → спойлер «Ручное действие».
   Ручной редактор не выносится наверх: основной способ работы — действия прямо на кадре.
4. **Три зоны страницы:** слева форма «Открыть вкладки» (sticky), справа вкладки и метрики,
   внизу «Автоматизация» (триггеры, макросы, файлы). Новые функции попадают в одну из этих зон,
   а не в новую карточку между ними.
5. **Текст.** Подписи полей: 11px, uppercase, `--txt-3`. Подсказки: 11.5px, одна строка, без повторов
   того, что уже сказано подписью. Никаких эмодзи-сердечек в заголовках.
6. **Состояния.** Статус вкладки — цвет точки: мятный «воспроизводится», голубой «готова»,
   жёлтый «ждёт», красный «ошибка/блок», серый «остановлена». Toast — единственный способ сообщить
   результат действия.
7. **Адаптив.** До 900px — одна колонка, форма не sticky; до 600px — кнопки в ряд с переносом.
8. **Универсальные компоненты, а не отдельные страницы.** Панель сценария (прогресс, запись, повторы, сохранение,
   выбор шага), список шагов с описаниями, редактор шага и триггеры — один шаблон и один код в `static/browser-core.js`,
   который используется везде: карточки вкладок Playwright, режим «Мой Chrome», страница «Сценарии». Если компонент
   понадобился на новом месте, он подключается оттуда, а не копируется. Разметка, которая живёт только на одной странице,
   считается долгом и переносится в общий модуль при ближайшей правке.

## Как подключить (одна строка, без конфликтов с текущей разметкой)

```html
  <link rel="stylesheet" href="/katya.css">
</head>
```

После подключения старые CSS-слои в `<style>` можно удалять блоками, проверяя страницу на 1440px и 390px.
