# Katya Browser Lab — дизайн-бриф

Общий документ для всех, кто правит панель: люди, Claude, Codex. Цель: одна спокойная система, где функции
сгруппированы по задаче, а не по дате появления.

Рабочая панель — React + TypeScript в `web/` (отдаётся по `/`). Старые страницы `static/index.html` и
`static/scenarios.html` остаются как `/legacy` и больше не развиваются.

## Структура `web/src`

```
main.tsx            точка входа: токены, базовые стили, UnlockGate
app/                оболочка: App (режимы, раскладка), Header, Diagnostics, UnlockGate
api/                запросы к серверу: client (fetch + заголовки), tabs, automation, unlock
lib/                чистые помощники без React: types, steps (описания шагов), stepCatalog (словари),
                    storage (localStorage/sessionStorage), sources (выбор сценария/макроса), text, toast, cx
hooks/              useLive (WebSocket), useLibrary (сценарии + макросы), useRecorder (запись шагов)
ui/                 переиспользуемые элементы: Toast, MethodSwitch, SourceSelect (+ ui.css)
features/scenario   универсальная панель «Сценарий»: прогресс, запись, список шагов, редактор, ручное действие
features/tabs       форма «Открыть вкладки», карточки вкладок Playwright, живой кадр и ввод на нём
features/chrome     режим «Мой Chrome»: мост к расширению, обновление расширения, кадр, видео
features/automation триггеры, макросы, файлы, ключ API
features/scenarios  страница-редактор сохранённых сценариев
styles/             tokens.css (цвета, радиусы, отступы, шрифты) и base.css (сброс, формы, кнопки, карточки)
```

## Правила кода

1. **Один компонент — один файл, не больше ~150 строк.** Логика с состоянием уходит в хук рядом
   (`useLiveFrame.ts`, `useChromeTab.ts`), разметка остаётся в компоненте.
2. **Общее — в `lib/`, `hooks/`, `ui/`.** Описание шага, выбор источника, тост, склонения — одна функция на все экраны.
   Если помощник понадобился второй фиче, он переезжает из фичи в общий слой, а не копируется.
3. **Стили рядом с фичей** (`features/tabs/tabs.css`), классы с префиксом фичи (`tab-`, `chrome-`, `auto-`, `scn-`).
   Цвета, радиусы и отступы — только токены из `styles/tokens.css`. Inline `style` не используется.
4. **Один вид кнопок**: `.btn` и модификаторы `-primary` (главное действие, мятная заливка), `-accent`, `-info`,
   `-danger` (запись, стоп, удаление), `-ghost` (второстепенные), размеры `-sm` / `-lg`, `-icon`.
5. **Текст.** Подписи полей: 11px, uppercase, `--txt-3`. Подсказки `.hint`: 11.5px, одна строка, без повторов подписи.
   Результат действия сообщает только тост (`lib/toast`).
6. **Состояния вкладки** — цвет точки `.dot`: мятный «воспроизводится», голубой «готова», жёлтый «ждёт»,
   красный «ошибка/блок», серый «остановлена».
7. **Форматирование**: `pnpm format` (prettier, 110 символов), `pnpm lint` (eslint + react-hooks), `pnpm typecheck`.
   Никаких многострочных однострочников вида `a; b; c`.

## Раскладка

- Слева форма запуска (sticky), справа вкладки и их карточки, ниже спойлеры «Триггеры, макросы и файлы» и
  «Диагностика сервера». Новые функции попадают в одну из этих зон, а не в новую карточку между ними.
- Иерархия карточки вкладки сверху вниз: плитка (миниатюра, адрес, состояние) → живой кадр → строка состояния →
  кнопки вкладки → адрес → панель «Сценарий». Основной способ работы — действия прямо на кадре.
- Адаптив: до 900px — одна колонка, форма не sticky; до 600px — кнопки в ряд с переносом. Проверять на 1440px и 390px.
