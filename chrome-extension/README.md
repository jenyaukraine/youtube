# Katya Browser Bridge

Расширение запускает шаги в выбранной вкладке установленного Chrome. Оно не переносит учётную запись из серверного браузера. Войдите в нужный сайт вручную в Chrome, затем подключите вкладку.

## Установка

1. В основной панели выберите «Мой Chrome · расширение», скачайте `Katya-Browser-Bridge.zip` из инструкции и распакуйте в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите «Режим разработчика» и выберите «Загрузить распакованное».
3. Выберите папку с `manifest.json`. Закрепите значок расширения.
4. Откройте вкладку сайта, нажмите значок расширения и «Подключить эту вкладку».
5. Вернитесь на основную панель, выберите сценарий или запишите действия.

Расширение запрашивает доступ к сайтам, чтобы работать с любой подключённой пользователем вкладкой. Управление принимает только от страницы `katya-dev.duckdns.org` или локального сервера `127.0.0.1:8010` / `localhost:8010`. Без подключения вкладки через значок расширения действия не выполняются. Пароли не записываются, действия на `accounts.google.com` отключены.

Исполнение кликов и ввода основано на DOM событиях расширения. Некоторые сайты требуют настоящие аппаратные события и могут не принять такие действия. Ограничения и проверки сайтов остаются в силе.
