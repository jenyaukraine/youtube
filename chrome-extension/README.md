# Katya Browser Bridge

Расширение показывает живой кадр выбранной вкладки Chrome в панели и передаёт в неё мышь, колесо и клавиатуру. Вкладка остаётся в фоне. Оно не переносит учётную запись из серверного браузера. Войдите в нужный сайт вручную в Chrome, затем подключите вкладку.

## Установка

1. В основной панели выберите «Мой Chrome · расширение», скачайте `Katya-Browser-Bridge.zip` из инструкции и распакуйте в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите «Режим разработчика» и выберите «Загрузить распакованное».
3. Выберите папку с `manifest.json`. Закрепите значок расширения.
4. Откройте вкладку сайта, нажмите значок расширения и «Подключить эту вкладку».
5. Вернитесь на основную панель, выберите сценарий или запишите действия.

После установки новой версии замените файлы в распакованной папке и нажмите «Обновить» на карточке расширения в `chrome://extensions`.

Расширение запрашивает доступ к сайтам и разрешение Chrome на отладку выбранной вкладки: через него получает кадры и передаёт ввод без переключения с панели. Chrome может показать своё уведомление об отладке. Управление принимает только от страницы `katya-dev.duckdns.org` или локального сервера `127.0.0.1:8010` / `localhost:8010`. Без подключения вкладки через значок расширения действия не выполняются. Пароли не записываются, действия на `accounts.google.com` отключены.

Клики, перемещение мыши и клавиатура передаются через интерфейс отладки Chrome; действия по селекторам ищут элементы на странице. На видео в панели доступны пауза и перемотка. Ограничения и проверки сайтов остаются в силе.
